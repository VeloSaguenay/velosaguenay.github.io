## 🎯 Organisation

Tous les fichiers de documentation doivent être placés dans ce dossier `docs/` pour maintenir une structure de projet propre et organisée.

### Conventions

- Utilisez des noms de fichiers descriptifs en MAJUSCULES avec underscores (ex: `FACEBOOK_SHARING_GUIDE.md`)
- Incluez toujours un en-tête de niveau 1 (`#`) au début du document
- Organisez le contenu avec des sections claires
- Ajoutez des emojis pour améliorer la lisibilité (optionnel mais recommandé)
